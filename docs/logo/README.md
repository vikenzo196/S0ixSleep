# Logo

| File | Use |
|---|---|
| `wordmark-dark.svg`, `wordmark-light.svg` | README header (dark and light theme) |
| `mark.svg` | Mark for dark backgrounds |
| `mark-mono.svg` | One-colour mark for light backgrounds |
| `icon.svg`, `icon-512.png`, `icon-128.png` | Square icon |
| `social-preview.svg`, `social-preview.png` | GitHub social preview (1280×640) |

Colours: navy `#10162A`, ivory `#ECE8DC`, moon `#F5C451`, grey `#A9B0C4`.

The text is set in [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) Bold and Medium (SIL Open Font
License 1.1) and converted to outlines, with a custom slashed zero. The logo files are covered by this
repository's license.
